# Button
Szögletes, mono feliratú gomb három változatban: primary (crimson kitöltés), outline és szöveges link nyíllal.

- `.vl-btn.vl-btn--primary`: oldalanként egy fő akció (pl. *View projects*). Szöveg: `on-crimson`.
- `.vl-btn.vl-btn--outline`: másodlagos akció. Keret `line-strong`, hoverre `crimson`.
- `.vl-link`: „View all” típusú továbblépés, hosszú nyíllal, hoverre a nyíl 4px-et jobbra csúszik.
- Felirat csupa nagybetű, `label` stílus. Ikon mindig a felirat után.
