# SectionHeader
Szekciócím csupa nagybetűvel, utána a sort kitöltő hajszálvonal, opcionálisan jobb oldalt egy `.vl-link`.

- Cím: `heading-2`. Vonal: `line` token, 1px.
- Eyebrow (`.vl-label.vl-eyebrow`): crimson-text, `//` kód-komment előtaggal. Ez a rendszer saját gesztusa, a fejlesztői identitásra utal.
