# Timeline
Idővonal munkához és tanulmányokhoz. Mobilon egy oszlop bal oldali vonallal, 760px felett (`.vl-timeline--split`) váltakozó két oldal középső vonallal.

- Pont: `bg` kitöltés, 2px `crimson` keret. A vonal `crimson` → `line` átmenet.
- Dátum `label` stílusban, cím `crimson-text`, intézmény `ink`, leírás `ink-muted`.
- Dátumot csak valós adattal írj; ha nincs, „Now” vagy „Past”. Sorrend: a jelenlegiek elöl, a múltbéliek utána, legújabbtól a régebbiig.
