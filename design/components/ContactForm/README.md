# ContactForm
Kontakt űrlap panelben (a 2. inspirációból): név, e-mail, üzenet, teljes szélességű primary gomb.

- Panel: `surface`, `line` keret, `radius-md`. Input: `bg` háttér, `line-strong` keret, `radius-sm`.
- Címke mindig látható `label` stílussal (nem csak placeholder).
- Fókusz: `focus-ring`.
