# TechRow
„Tech I work with” ikonsor a hero alatt: 44px négyzetek márka-ikonnal (Simple Icons, `currentColor`), `radius-md` sarokkal. Hoverre vagy billentyűzet-fókuszra alatta megjelenik a technológia neve.

- Alapból `ink-muted` ikon, hoverre `ink` ikon, `crimson` keret, `surface-raised` háttér.
- A név `label` stílusban, `crimson-text`, 4px-es felcsúszással jelenik meg.
- Minden elem `tabindex="0"`, hogy billentyűzettel is elérhető legyen.
- Max 9 elem; a teljes lista az About oldalon van. Az élő oldalon a `react-icons` `Si*` ikonjai ugyanezek.
